CHOSES À FAIRE EN DÉMARRANT LA STATION

1. Télécharger MongoDB Community Server
   Lien : https://mongodb.com

2. Démarrer le Backend
   1. cd TP4_PoC_Prototype_MVP\yrr_mvp\backend
   2. python -m venv .venv
   3. .\.venv\Scripts\Activate.ps1
   4. pip install django djangorestframework django-cors-headers "pymongo[srv]"
   5. $env:MONGODB_URI="mongodb://localhost:27017/"
   6. python manage.py migrate
   7. python manage.py runserver 8000

3. Démarrer le Frontend
   1. cd TP4_PoC_Prototype_MVP\yrr_mvp\frontend
   2. npm install
   3. npm install connect-history-api-fallback --save-dev
   4. ..\scripts\setup-hosts.ps1
   5. npm run dev

Accès au site :
- Officiel : https://yachtracingresults.yrr
- Local : http://localhost:5173/
